Put your brand images in this folder (or in `Asset/` if you prefer that name):

- logo.png -> round logo shown above the title
- hero.jpg -> top cover image background
- facebook.png -> icon inside Facebook button
- instagram.png -> icon inside Instagram button
- tiktok.png -> icon inside TikTok button

Allowed image types: png, jpg, jpeg, webp
Name matching is flexible (`logo.png` and `Logo.png` both work).
The current logo file `Nile_craft_circle_border_visible_transparent.png` is also supported.
If any file is missing, the page falls back to built-in styling/icons.
